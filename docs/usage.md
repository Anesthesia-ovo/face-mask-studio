# 使用说明

FaceMaskStudio 在本机批量处理图片和视频：选择保留的主要人物，再为其他检测到的人脸添加马赛克、模糊或纯色遮挡。

## 启动与添加素材

解压 Windows 便携包，双击 `FaceMaskStudio.exe`。EXE 同目录下的 `_internal` 包含运行库和模型，必须完整保留。程序可以放在有写入权限的本地文件夹，不需要安装 Python。

公开发布包解压即可处理图片。视频导出还需要本地 FFmpeg 编码器；在解压目录打开 PowerShell，执行一次：

```powershell
powershell -ExecutionPolicy Bypass -File ".\准备视频组件.ps1"
```

此准备脚本需要网络，从固定地址下载并验证 FFmpeg ZIP 后，提取编码器到 `_internal/assets/ffmpeg.exe`。准备完成后，视频处理也可完全离线。GUI 不会自动下载组件。离线电脑可使用另一台电脑已经准备好的完整程序目录；需要手动安装时，将经核验的官方 Gyan `ffmpeg.exe` 复制到上述位置。

点击“添加文件”选择图片或视频；也可以点击“添加文件夹”。勾选“文件夹包含子文件夹”后，会递归添加受支持的素材。图片和视频可以混合放入队列。

点击队列中的一条素材，在中央预览该文件。绿色框表示保留人脸，橙色框表示遮挡人脸；紫色虚线框表示手工补充的遮挡区域。

## 选择保留的人物

| 模式 | 适用情况 | 需要检查的内容 |
| --- | --- | --- |
| 自动保留最大人脸 | 主角靠近镜头，脸部明显比其他人更大 | 人物大小交替时，自动保留对象可能变化 |
| 手动保留指定人脸 | 需要明确保留某个人，或同时保留多个人 | 选择清晰参考帧，导出后检查人物匹配结果 |
| 遮挡全部人脸 | 画面中的每个人都需要遮挡 | 检查漏检区域，必要时补框 |

程序默认“自动保留最大人脸”。若想调整，在“原图与选框”视图中点击人脸识别框：绿色框可改为遮挡，橙色框可改为保留。点击操作会将当前文件切换为手动模式。可以同时保留多个人，也可以取消全部保留。

每个文件的人物选择独立保存于本次会话；不会自动套用到队列中的其他素材。点击“重置本文件调整”，可清除该文件的手动选择和补框，重新使用当前全局模式。程序不提供项目保存，关闭后需要重新选择素材和人物。

视频可以拖动时间滑块，在人物脸部清晰、较正面的帧中选择主角。本地模型提取所选脸部特征并逐帧匹配；无法可靠识别时会保守遮挡。参考帧和特征保存在当前处理内存中，不会上传。

## 手工补框

当检测不到需要遮挡的区域时，选择“拖框补充遮挡”，在预览中拖出矩形。补框最小尺寸为 8 × 8 像素。

- 图片：补框直接用于遮挡选定区域。
- 视频：补框以当前帧为编辑帧，从该帧开始向后跟随区域移动。该编辑帧之前不会应用此补框。
- 已有补框时：回到同一编辑帧继续修改；要在另一帧重新设定，请先“重置本文件调整”。当前版本每个文件只使用一个手工框编辑帧。
- 点击“撤销最后一个手工框”，删除最近添加的补框。

补框使用画面中的运动特征跟随，不会自动理解框内人物的身份。明显转场或持续跟踪失败会使补框停止，日志会提示需要复核的情况。需要保护整段视频时，尽量在第一帧或需要开始遮挡的位置建立补框；复杂剪辑可以先分段处理。

预览只在编辑帧显示手工框，不播放跟随动画。完整效果需要查看导出视频。

## 调整遮挡与检测

切换到“遮挡效果”检查结果，再调整右侧设置。

| 设置 | 作用 |
| --- | --- |
| 马赛克 | 将脸部区域像素化；强度越高，块状效果越明显 |
| 高斯模糊 | 使选定区域模糊；较弱模糊仍可能辨认人物 |
| 纯色遮挡 | 使用纯色覆盖选定区域 |
| 扩边 | 扩大识别框外的遮挡范围，减少边缘残留 |
| 检测精度 | 提高检测分辨率可改善小脸识别，同时增加处理时间 |
| 检测阈值 | 降低阈值可能减少漏检，也可能增加误检 |

远处小脸可尝试“高精度”，再降低检测阈值。先用单个文件验证效果，再对整个队列导出。

## 批量导出

选择本地导出目录，点击开始批量处理。每个文件显示自己的状态，视频处理时显示帧进度；取消操作会停止正在处理的任务。单个文件失败后，程序会记录原因并继续处理其他文件。

图片导出为 PNG，透明通道会保留，EXIF 方向会应用，原始 EXIF 与位置元数据不写入输出。视频导出为 MP4 / H.264；启用保留音轨时，将原音轨转为 AAC。奇数宽高的视频会补齐到适合编码的偶数尺寸。

程序创建新文件，重复导出会自动改名，不覆盖原素材或已有结果。处理中使用临时文件，正常取消或失败后会清理未完成结果。点击“日志”查看具体错误与跟踪提示。

## 导出后复核

查看成品中的所有需要保护的人脸，特别检查远处小脸、转身、快速运动、遮挡、人员交叉和转场。视频检测会逐帧运行，光流最多短时补偿约 0.7 秒的漏检；补偿结束后仍可能暴露人脸。

自动模式每帧保留最大人脸，无法保证始终保留同一个人。遇到人物大小交替，改用手动保留。较高隐私要求可使用纯色遮挡并适当扩边，同时检查服装、声音、环境等是否仍可识别人物。

若导出结果需要修改，回到原素材调整设置或选择，然后重新导出。当前版本不支持在已经输出的视频上编辑时间线或为多段画面保存不同关键帧。

## 常见问题

**启动提示缺少文件或模型**

重新解压完整便携包，确认 EXE 与 `_internal` 在同一目录。若提示缺少视频编码器，先运行发布包的 `准备视频组件.ps1`。源码运行时，先执行 `scripts/fetch_resources.py`，再从 `src/launcher.py` 启动。

**Windows 提示未知发布者**

当前便携程序未签名。请确认下载来自本仓库发布页，检查对应哈希，并使用本机安全软件扫描。资源来源和现有验证边界见[安全说明](security.md)。

**检测不到人脸**

检查预览帧、提高检测精度或降低阈值；依然漏检时可使用手工补框。背脸和严重遮挡通常缺少可识别的面部特征。

**手机视频出现音画同步变化**

当前视频导出使用原素材平均帧率转为固定帧率，不能保持所有可变帧率时间戳。请检查同步，必要时先用本地视频工具转换为固定帧率再处理。

**动态图片无法添加或读取**

当前只处理单帧图片和视频，不支持动态 GIF 或其他多帧图片。请先将动态素材转换为视频。

**网络共享文件无法读取**

输入仅限本地磁盘。网址、UNC 网络共享和映射网络盘会被拒绝；请先将素材复制到本地文件夹。
