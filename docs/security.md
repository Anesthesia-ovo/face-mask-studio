# 离线设计与验证说明

FaceMaskStudio 的识别、跟踪、预览和导出在本机完成。程序没有登录、素材上传、统计遥测、自动更新或运行时模型下载功能。本文区分程序的离线设计、已执行的验证，以及尚未得到的验证结果。

## 运行时与构建阶段

| 阶段 | 网络行为 |
| --- | --- |
| 下载发布包 | 浏览器从 GitHub 下载，需要网络 |
| 安装开发依赖、准备构建资源 | `pip` 与 `scripts/fetch_resources.py` 获取固定依赖和资源，需要网络 |
| 首次准备发布包的视频组件 | 独立 `准备视频组件.ps1` 下载并核验 FFmpeg，需要网络 |
| 启动便携 EXE | 使用包内 Python、模型与已经准备的本地编码器，无需网络 |
| 预览、人物匹配、批量导出、自检 | 在本机处理本地文件，无需网络 |
| `fetch_resources.py --verify-only` | 只检查现有本地文件与固定 SHA-256，无网络下载 |

构建下载脚本不打包进 EXE。公开发布包包含单独的视频准备脚本，它只在用户主动运行时联网；GUI 不会调用它。程序在资源缺失时报告错误，不会自动联网补充。离线开发环境可以预先准备已核验的依赖和资源，再使用 `build.ps1 -SkipInstall -SkipDownload`。

公开发布包不附带独立 Gyan FFmpeg 编码器，以便其下载与本地使用和本项目的二进制分发分开进行。视频准备脚本验证 ZIP 的固定 SHA-256，只提取所需的 `ffmpeg.exe`。OpenCV 轮子内的 LGPL FFmpeg 组件随发布包提供，并附有相应的许可证与对应源码包；它和视频导出需要的独立编码器是两个组件。

对应源码包 `FaceMaskStudio-1.0.0-OpenCV-FFmpeg-sources.zip` 和 Windows 便携包一同提供于 [Releases](https://github.com/Anesthesia-ovo/face-mask-studio/releases)。第三方组件的详细说明见 [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。

## 实现中的限制

- 程序入口 `src/launcher.py` 启用 `src/offline.py`，禁用 Python 层常见 TCP、UDP、DNS 和创建连接接口。
- 输入与输出路径检查拒绝 URL、UNC 共享和 Windows 映射网络盘，并在解析路径后再次检查远程位置。
- OpenCV 视频读取强制使用 FFmpeg 后端，限定 `file,pipe` 协议和允许的媒体格式。
- 独立 FFmpeg 编码器使用参数列表启动，`shell=False`；原音轨读取也受到本地协议与格式限制。
- 图片依据内容使用 JPEG、PNG、BMP、TIFF、WebP 解码白名单，多帧图片和异常巨大图片会被拒绝。
- 人物选择参考帧与脸部特征仅用于当前处理会话；输出图片移除原始 EXIF 与位置元数据。

这些是本程序入口和媒体处理路径中的限制，并非操作系统防火墙或完整进程沙箱。FFmpeg 原始构建包含其他协议能力，但应用只以限定的参数调用它。直接调用第三方二进制、修改入口或替换依赖不属于这里验证的运行方式。

## 资源来源与完整性

模型来自 OpenCV 官方 `opencv_zoo` 仓库，使用固定源提交与固定 ONNX SHA-256。YuNet 用于人脸检测，SFace 用于手动选定人物的本地匹配。FFmpeg Windows 构建来自 FFmpeg 官方下载页列出的 Gyan 构建站点。

构建脚本记录并验证这些资源的 SHA-256，准确 URL、模型提交和哈希见 [`resources/manifest.json`](../resources/manifest.json)。Python 开发依赖采用固定版本，构建依赖文件记录对应 wheel 哈希。

哈希匹配说明下载内容与记录一致，可以发现传输损坏或内容替换；它不能单独证明上游资源没有漏洞，也不是杀毒扫描认证。请保留发布包中的第三方许可证与资源来源说明。

## 已执行的功能与离线验证

首个完整 Windows 本地构建使用 Python 3.12.14、OpenCV 4.14.0.94、NumPy 2.2.6、Pillow 12.3.0 与 PyInstaller 6.22.3。该构建包含本地 FFmpeg 编码器，构建阶段完成了以下验证：

- 12 项引擎测试，覆盖移动跟踪、手工框、人物保留、音轨、中文路径、透明通道、EXIF 方向、奇数尺寸、取消及失败清理、重复导出和内容格式限制。
- 双人物移动素材集成检查，确认主角保留、背景人物遮挡和视频导出。
- 界面检查，覆盖人脸点击调整、手工框、批量导出，以及小窗口中的控件可用性。
- 打包 EXE 自检，覆盖 Python 网络限制、YuNet 加载、遮挡像素变化、中文图片输入输出，以及 FFmpeg 视频编码。
- 内容伪装检查：拒绝改名为 PNG 的 EPS，以及改名为 MP4 的网络播放列表。
- 源码审查：应用没有远程请求、登录、遥测、更新、上传、`eval` 或 shell 命令拼接路径。

公开发布包的完整视频自检需要先准备视频组件。上述验证证明所检查的样例和路径能够正常运行，不能保证所有视频、所有面孔或未来依赖版本都具有相同表现。公共仓库的可复现测试使用合成图像和本地生成视频，不需要上传私人素材。

## 杀毒扫描与签名状态

在首个构建环境中，尝试使用 Microsoft Defender 自定义扫描最终程序目录，扫描器返回 `0x80004005`，没有得到有效的“扫描通过”结果。备用 ClamAV 官方病毒库请求返回 HTTP 403，也未完成扫描。因此本项目不声称该构建已经通过杀毒认证，也不声称“绝对无毒”。

Windows 便携版尚未进行代码签名，可能显示未知发布者提示。建议从本仓库发布页下载，核对发布文件哈希，并使用本机安全软件对完整解压目录进行扫描。

## 遮挡结果的边界

面部检测和跟踪可能漏掉小脸、侧脸、快速运动或严重遮挡。自动最大人脸模式可能在人物大小变化时换人；手动人物匹配可能失败；补框遇到转场或持续跟踪失败会停止。视频导出日志会记录相关提示，但无法自动判断所有遗漏。

遮挡效果也不会清除服装、体态、声音、位置和环境中可能识别人物的信息。请在对外分享前检查成品，按实际保护需求选择遮挡方式和范围。
